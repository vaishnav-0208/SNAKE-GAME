## 🐍 Python Snake Game
A simple Snake Game built using **Python and Tkinter**.
## 🎮 Features
* Arrow-key controls
* Food and snake growth
* Wall & self collision
* Restart button
## 🛠️ Technologies
* Python 3.14
* Tkinter
## ▶️ Run
```bash
python snake.py
```
## 🎮 Controls
⬆️ Up | ⬇️ Down | ⬅️ Left | ➡️ Right
